# Typora + GitHub 知识库同步：Git 命令速查手册

本手册记录了从零配置本地 Git 环境，到成功建立安全通道并推送知识库至 GitHub 的完整运维命令。

## 一、 环境初始化与全局配置

当你在新电脑上安装完 Git 后，需要执行一次基础身份宣告及白名单配置。

Bash

```
# 1. 配置全局提交者姓名（换成你的 GitHub 用户名）
git config --global user.name "sobermeng166"

# 2. 配置全局提交者邮箱（换成你的 GitHub 绑定邮箱）
git config --global user.email "chengmmeng@outlook.com"

# 3. 查看当前所有的 Git 全局配置列表
git config --list

# 4. 解决安全机制拦截：将 NAS/网络共享路径加入 Git 全局白名单
git config --global --add safe.directory '%(prefix)///10.24.32.134/home/knowledge-base'
```

## 二、 SSH 密钥免密安全通道配置

为了实现高频、无感的自动化同步，使用 SSH 密钥对替代传统的账号密码。

Bash

```
# 1. 生成高强度 RSA 密钥对（提示输入密码时连敲回车保持为空即可）
ssh-keygen -t rsa -b 4096 -C "chengmmeng@outlook.com"

# 2. 查看并打印公钥内容（完整复制输出结果并粘贴至 GitHub Settings -> SSH Keys）
cat ~/.ssh/id_rsa.pub

# 3. 测试本地与 GitHub 的安全加密通道是否彻底打通（注意 ssh 与 -T 之间有空格）
ssh -T git@github.com
```

## 三、 本地知识库首次初始化与“强推上云”

在包含 `SUMMARY.md` 和 `chapter1` 的本地笔记根目录下运行，用于建立版本库并完成首次发布。

Bash

```
# 1. 将当前所在文件夹初始化为一个全新的 Git 本地版本库
git init

# 2. 将目录下所有文档、层级分类文件夹及资产添加至暂存区
git add .

# 3. 将暂存区内容正式提交到本地版本库，并备注版本说明
git commit -m "feat: 首次初始化本地网络与运维知识库"

# 4. 强制将当前本地分支重命名为 GitBook 官方推荐的 main 分支
git branch -M main

# 5. 关联远程 GitHub 仓库（使用加密的 SSH 地址）
git remote add origin git@github.com:sobermeng166/my-knowledge-base.git

# 6. 核心闭坑连招：强制覆盖远程仓库（忽略网页端自动生成的 README，本地主权强推）
git push -u origin main -f
```

## 四、 日常更新与运维脚本（建议打包为 `sync.bat`）

知识库搭建完成后，后续在 Typora 里新增或修改了笔记，只需执行这三行命令（或双击运行 `sync.bat` 批处理文件）：

Bash

```
# 1. 抓取本地所有的修改与新增文章
git add .

# 2. 提交更新，并自动生成带当前时间的日志备注
git commit -m "auto_sync: %date% %time%"

# 3. 推送到 GitHub 仓库主干，瞬间触发云端 GitBook 通过 Webhook 自动渲染
git push origin main
```
